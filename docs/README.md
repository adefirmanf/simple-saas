## 🔍 How to Use

### Viewing Diagrams
All diagrams are written in **Mermaid** syntax and can be viewed:
1. **GitHub**: Automatically renders Mermaid diagrams
2. **VS Code**: Use the "Markdown Preview Mermaid Support" extension
3. **Online**: Copy to [Mermaid Live Editor](https://mermaid.live/)
4. **Documentation Sites**: Compatible with GitBook, Docusaurus, and similar tools

### For Portfolio Use
1. Review [ARCHITECTURE.md](../ARCHITECTURE.md) for comprehensive documentation
2. Use [DIAGRAMS.md](./DIAGRAMS.md) for quick visual references
3. Copy diagrams into presentations or portfolio documents
4. Screenshots can be taken from rendered diagrams

## 📊 Diagram Types

- **System Diagrams**: High-level architecture and component relationships
- **Sequence Diagrams**: Flow of operations and interactions
- **ERD (Entity-Relationship)**: Database schema and relationships
- **Flowcharts**: Data flow and decision processes
- **Dependency Graphs**: Technology stack and dependencies

## 🚀 Technologies Documented

- Frontend: Next.js 14, React 18, TypeScript, Tailwind CSS
- Backend: Next.js Server Actions, NextAuth.js, Prisma ORM
- Database: SQLite with Prisma
- Security: Zod validation, bcryptjs, JWT tokens
- Tools: ESLint, TypeScript compiler, PostCSS
